use python and sqlite.

build a web application that has these modules:

 1. list of courses
   - course name
   - date
   - list of students

 2. list of students
   - student name
   - address
   - email
   - contact number

 3. announcement module
   - title
   - content
   - can accept uploads (images - poster of courses etc)
   - date 

two types of users:
admin and student

there will be simple security using username and password.

admin can create the courses.
admin can approve students enrollment in the courses.
admin can create announcements.

students can enroll in the course.
students can only see list of currently available courses.
students can see other student names in the same enrolled course.

always adhere to best practices for software architecture and security.

ui design should have a login page.
all users must login first.
the page after login should display the announcements made by admin.

use best practice for ui/ux
